# 📋 Akıllı Görev Yöneticisi

NLP destekli görev yönetim uygulaması.

## Özellikler
- ✅ Görev ekleme, silme, tamamlama
- ✅ Kural tabanlı otomatik kategori belirleme (NLP)

## Kurulum
```bash
# Repo'yu klonla
git clone https://github.com/kullanici/to_do_app.git
cd to_do_app

# Sanal ortam oluştur
python -m venv venv
source venv/bin/activate  # Mac/Linux
venv\Scripts\activate     # Windows

# Paketleri yükle
pip install -r requirements.txt

# Çalıştır
python app.py
```

## Teknolojiler
- Python 3.10
- Flask
- SQLite + SQLAlchemy
- Bootstrap 5
